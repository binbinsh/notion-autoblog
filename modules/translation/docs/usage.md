# translation module usage

## Purpose

The `translation` module renders a machine-translation notice at the top of a translated page, for multilingual content generated by `notion-autoblog`.

## How to include it

```toml
[module]
  replacements = "github.com/binbinsh/notion-autoblog/modules/translation -> ../notion-autoblog/modules/translation"

  [[module.imports]]
    path = "github.com/binbinsh/notion-autoblog/modules/translation"
```

If your local directory is not named `notion-autoblog`, update the replacement path to match.

## Partial

Call it directly from the article template:

```go-html-template
{{ partial "translation/notice.html" . }}
```

The module renders the notice automatically when the page front matter contains:

- `notion_source_language`
- `notion_translation_language`
- `notion_source_path`

## Shortcode

To control the notice position by hand, use the shortcode in Markdown:

```md
{{< translation-note sourceLang="zh" sourcePath="posts/example.zh.md" >}}
```

Without explicit arguments the shortcode falls back to the current page's front matter.
